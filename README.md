# Apollo 13 — Loom demo tree

End-of-mission record of Apollo 13 as a `thread.json` tree.

Schema and validators are loom-warp, not this repo. Every node has
`sourceVerified` false. NASA PDFs in `artifacts/` are public-domain
government works.

The root is a finished 1970 record. Live status does not get written
onto a closed node.

Not the official first-tree home.
